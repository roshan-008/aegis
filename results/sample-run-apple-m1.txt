===== bench_mmap =====
aegis mmap bench: N=10000000  (binary 240.0 MB)

CSV parse + compute           2.793 s        3.6 M rows/sec
binary read + compute         0.068 s      146.8 M rows/sec
mmap pass 1 + compute         0.038 s      263.2 M rows/sec
mmap pass 2 + compute         0.029 s      346.2 M rows/sec

Robust finding (cache-state-independent):
  text CSV parsing is ~97x slower than any binary path — parsing,
  not I/O, dominates. Binary read and mmap are both far faster and,
  with the page cache warm, within noise of each other; mmap's
  distinct benefit is zero-copy (no 76 MB payload allocation).
  Cold-cache read-vs-mmap is NOT measured here (needs purge) — that
  claim is deferred rather than faked.
roundtrip correctness: ok
